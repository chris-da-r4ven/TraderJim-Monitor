# TraderJim-Monitor

Lese-App (Web-App) für ein privates Paper-Trading-Experiment. Dieses Repository enthält nur den App-Code.
Die Daten liegen in einem privaten Repository und werden mit einem persönlichen Lese-Schlüssel abgerufen,
der nur auf dem Gerät des Nutzers gespeichert wird. Ohne Schlüssel zeigt die App nichts an.
